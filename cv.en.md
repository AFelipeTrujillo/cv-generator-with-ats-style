# Candidate fact sheet — English

This file is the only source of truth in English. Fill in only what is true. If you do not know it or it does not apply, leave it blank. Delete blocks you do not use. If you need more jobs, projects, degrees, or courses, copy a block and paste it below.

You do not have to fill in the Spanish sheet as well. If only this file is filled in, the AI writes the Spanish CV from these facts, using the usual terms of your field.

The section "How to fill this in" is help for you. It is not CV data.

## How to fill this in

- Write in your own words. It does not need to sound like a CV.
- One idea per line when there is a list.
- If you have a real figure (people, clients, %, time, money), write it. If you do not remember it, do not add a number.
- Do not copy requirements from a job ad into this file. This file is only what you have already done.
